# Cài đặt

## Yêu cầu hệ thống

- Rust toolchain từ **1.85** trở lên (tương thích edition 2024) — cài qua [rustup](https://rustup.rs/)
- Hệ điều hành: Windows, Linux, macOS và các nền tảng khác có hỗ trợ terminal

## Build từ source

1. Clone dự án:

   ```sh
   git clone <repository-url>
   cd editor
   ```

2. Build bản phát hành:

   ```sh
   cargo build --release
   ```

3. Chạy chương trình:

   ```sh
   ./target/release/editor
   ```
