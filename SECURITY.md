# Security

The project takes security seriously. If you discover a security vulnerability, please report it following the process below.

## Reporting a vulnerability

- **Do not open a public issue** for security problems.
- Send the details via:
  - The repository's GitHub **Security Advisory** (preferred), or
  - Email: **<maingocphong216@gmail.com>**

## What to include

- A description of the vulnerability: type, potential impact
- Reproduction steps (if any)
- Affected version
- Suggested fix (if any)

## Response policy

- Acknowledgment within **7 business days**.
- Status updates throughout the process.
- Public disclosure after the vulnerability is fixed and a patch is released (for severe vulnerabilities).
